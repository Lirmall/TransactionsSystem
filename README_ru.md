
# TransactionsSystem

Учебный пет-проект для практического освоения новых навыков в программировании и работе с транзакциями.

## О проекте

TransactionsSystem — модульная система для управления пользователями, счетами и транзакциями. Цель проекта — закрепить знания в области архитектуры приложений, REST и SOAP сервисов, а также тестирования.

В процессе написания проекта исследовались следующие темы:
- **Многопоточность** - основы
- **Spring Framework** - аннотации и интеграции
- **Аспектно-ориентированное программирование (AOP)** - логирование методов через АОР
- **Настройка логера** - изменение, добавление логгеров
- **Hibernate / Spring Data** - изучение настройки и конфигурации
- **Конфигурирование пользовательских кэш-провайдеров; провайдеры для кэша второго уровня; реализации кэша второго уровня (EHCache); настройка кэша запросов**
- **Maven** - настройка многомодульного проекта
- **Юнит- и интеграционное тестирование**
- **Регулярные выражения**
- **Работа с контейнерами**
- **XML и SOAP**
## Использованные технологии

- Java 17 lts version
- Maven
- Spring boot 3.x (core, data, jpa, web)
- Hibernate 6.x
- PostgreSQL  14.1
- Flyway db migration
- Swagger   
- TestContainers
- JUnit 5
- Docker + compose

- Модульная архитектура:
    - ts-accounts — управление пользователями и счетами
    - ts-common — общие классы и DTO
    - ts-transactions — создание и обработка транзакций
    - ts-reports — отчеты по транзакциям

Наименование схемы БД - transactions.
Создание структуры БД для всех модулей происходит с помощью Flyway миграций, необходимо только подключение к БД по указанным в модулях адресам.

Проект поддерживает как запуск средствами idea, так и имеет реализацию генерации и запуска с помощью Docker-контейнеров

## Описание модулей

### ts-accounts

Этот модуль отвечает за все действия с пользователями и их банковскими аккаунтами как то CRUD-операции, а также верификацию данных и возможность проведения транзакции.

- База данных:  
  `jdbc:postgresql://localhost:5434/ts-accounts`  
  Пользователь/пароль: `postgres` / `pwpostgres`
- Swagger UI: `http://localhost:8089/swagger-ui/index.html`

В этом модуле реализовано:
- Минимальная настройка и конфигурация Hibernate / Spring Data
- Конфигурированы кэши 2 и 3 уровня
- Регулярные выражения
- Настройка логгеров
- Аспектно-ориентированное программирование в части логирования сервисов

### ts-transactions

Этот модуль отвечает за создание транзакций между банковскими аккаунтами пользователей.

- База данных:  
  `jdbc:postgresql://localhost:5435/ts-transactions`  
  Пользователь/пароль: `postgres` / `pwpostgres`
- Swagger UI: `http://localhost:8090/swagger-ui/index.html`
- Реализован SOAP Endpoint (о чем ниже)

Также этот модуль по Rest технологии взаимодействует с модулем accounts для получения данных о банковских счетах пользователей, участвующих в транзакциях.

Модуль на данный момент не завершен в некоторой части логики. Например, не реализована обработка выдачи наличных и сопутствующие этой процедуре проблемы и ограничения. Также в минимальном виде реализовано изменение статуса транзакции.

Дополнительно к обычным CRUD-операциям модуль имеет возможность создать множество записей в БД со случайными банковскими аккаунтами и данными отправки/прихода для проверки работы модуля отчетов. В дополнение к методу выше, модуль имеет метод очистки БД транзакций.

В этом модуле реализован **soap endpoint**. Он расположен по адресу `http://localhost:8090/soap/`. Эндпоинт реализует создание транзакции между пользователями. Структура xml запроса к эндпоинту следующая:

``` xml
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
                  xmlns:ts="http://tstransactions.klokov.ru/soap">
   <soapenv:Header/>
   <soapenv:Body>
      <ts:SoapTransactionRequestDto>
         <ts:senderId>1</ts:senderId>
         <ts:recipientId>2</ts:recipientId>
         <ts:amount>10.0</ts:amount>
         <ts:typeId>1</ts:typeId>
      </ts:SoapTransactionRequestDto>
   </soapenv:Body>
</soapenv:Envelope>
```

### ts-reports

Этот модуль отвечает за операции с отчетами. Позволяет получить отчеты из БД транзакций, очистить БД отчетов и искать по отчетом с помощью критериального поиска.

- База данных:  
  `jdbc:postgresql://localhost:5436/ts-reports`  
  Пользователь/пароль: `postgres` / `pwpostgres`
- Swagger UI: `http://localhost:8091/swagger-ui/index.html`

Также в этом модуле реализовано два вида получения отчетов из модуля транзакций - однопоточный и многопоточный. Для получения данных из модуля транзакций реализован ReportsService в котором
- fillAllOrNewReportsToDB() - однопоточное получение данных и запись их в БД
- concurrentFillAllOrNewReportsToDB() - многопоточное получение данных и запись их в БД

### ts-common

Этот модуль содержит классы, сущности, дто и многое другое, используемое двумя или более модулями приложения
